# Mock responses

Canned response bodies for the grounding API, matching [doc/api-contract.md](../doc/api-contract.md).
Use them to build and test the client without an API key or network. In mock mode the
backend serves these files instead of calling Gemini.

They were generated by running the real backend handler (`backend/src/app.py`) with
Gemini faked, so field names and types match what the server actually returns.

| File | Endpoint | HTTP status | Client should |
|---|---|---|---|
| `plan.json` | `POST /plan` | 200 | Highlight `target` for step 1 of 2 |
| `plan-no-target.json` | `POST /plan` | 200 | Steps known, first one not found: show "I couldn't find "Print"…" |
| `plan-no-steps.json` | `POST /plan` | 200 | Show "I could not work out the steps…" |
| `locate.json` | `POST /locate` | 200 | Highlight `target` for the next step |
| `locate-not-found.json` | `POST /locate` | 200 | Show "I couldn't find "{label}"…" |
| `error-bad-request.json` | either | 400 | Show "Something went wrong…" (client bug: fix the request) |
| `error-model.json` | `POST /plan` | 502 | Show "Something went wrong…" |
| `error-timeout.json` | `POST /plan` | 504 | Show "Something went wrong…" |

Coordinates are normalized 0–1 with a top-left origin. Multiply by the screenshot's
pixel width and height to get the box on screen.
